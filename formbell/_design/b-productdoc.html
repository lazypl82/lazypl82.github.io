01 / refund router

Refund requests go to billing

Your billing inbox gets refund requests, and nothing else.

Questions
Request type (multiple choice: Refund, Sales, Support), Order number, Name, Message
Rule
Request type is Refund → billing@acme.com
Email
Order number in the subject. Name, order number and message in the body.

Formbell only sends the email. You still approve and process the refund yourself.

02 / event confirmation

Confirm event registrations

When someone says yes, they get an email that names the session they picked.

Questions
Attendance (Yes, No), Name, Session. Add an Email question only if your form doesn't collect emails.
Rule
Attendance is Yes → the person who filled in the form
Email
Greet them by name and confirm you received their registration.

Don't promise a seat or a payment the form can't check.

03 / inquiry routing

Send each inquiry to the right person

Sales questions to sales, support questions to support.

Questions
Request type (multiple choice: Sales, Support, Billing), Name, Message
Rules
is Sales → sales@acme.com
is Support → support@acme.com
is Billing → billing@acme.com
