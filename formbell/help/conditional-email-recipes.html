Formbell

3 answer-based email recipes for Google Forms™

Each recipe automatically emails someone only when an answer matches. Formbell's free plan includes conditional rules: 1 rule at a time across your Google account, with every condition type. Start with one route on Free; running several routes together needs Pro.

These recipes do not include preconfigured Formbell rules. Create the questions in your own form, then create the rule in Formbell for that form.

1. Refund request router

Send refund requests to billing. Other request types are not emailed by this rule.

Questions

QuestionTypeUsed for
Request typeMultiple choice or dropdown, required: Refund / Sales / SupportThe condition
Order numberShort answer, requiredSubject and message
NameShort answerMessage
MessageParagraphThe reason for the refund

Rule

  • When: Request type is Refund
  • Send to: This address, for example your billing inbox
  • Subject: "Refund request for" + the Order number answer, added with Insert answer
  • Message: the Name, Order number and Message answers

Email collection is not needed, because the email goes to a fixed address. Formbell sends the request email only. It does not approve or process refunds.

2. Event registration confirmation

Email each person who says they will attend, with the session they chose.

Questions

QuestionTypeUsed for
AttendanceMultiple choice, required: Yes / NoThe condition
NameShort answer, requiredGreeting
SessionMultiple choice or dropdown, requiredSubject and message
Email (if not using collected email)Short answer, required, with email validationThe recipient

Rule

  • When: Attendance is Yes
  • Send to: The person who filled in the form. Choose Email collected by Google Forms if your form collects emails. If email collection is off or can't be checked, choose your Email question instead.
  • Subject: "Your registration for" + the Session answer
  • Message: greet them by Name and confirm that you received their registration for the Session

Say that you received the registration. Do not say that a seat or payment is confirmed, because the form cannot check that.

3. Inquiry routing by type

Send each kind of inquiry to the person who handles it.

Each route is one rule. On the free plan, one of these rules runs at a time. Running all three together needs Pro: $4 per month or $29 per year, taxes included. Use a single-choice question so each response matches one route. With checkbox conditions such as contains or is any of, one response can match several rules and send several emails.

Preview and send a test

  1. Submit a test response that matches the rule, using your own address where an email is needed.
  2. In the rule editor, preview the email with that response, then save the rule.
  3. On Free, if another rule is running in your account, choose which rule runs.
  4. Turn alerts on for the form, then use Send me a test. The test goes only to your own address.
  5. After a real response arrives, check the send log. Sent means Google accepted the email for sending. It does not confirm inbox delivery.

Limits

  • One condition per rule. No AND/OR combinations.
  • Each rule sends to one address. No CC or BCC.
  • Google's daily sending limits apply.
